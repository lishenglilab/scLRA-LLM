QC distributions

Metric definitions & analysis notesReference for all metric groups
Read IDs
Distinct BAM-derived read IDs per cell. Sample totals sum only retained cells.
Gene / transcript counts
Column totals in the corresponding linear RNA count matrices.
Detected genes / transcripts
Features with counts greater than zero in a cell.
MT
Mitochondrial gene counts / total gene counts × 100, recomputed from Nanopore counts.
UMI strings
Distinct strings pooled across genes within a cell; not gene-aware molecule counts.
Detection ratio
Detected transcripts / detected genes in the same cell.
Pearson r / Spearman ρ
Across cells within each sample, using the variable pairs stated in the column headers.
double.cell
Existing labels inherited from matched filtered Illumina metadata. False is a label, not a measured residual doublet rate.
Detected features
Distinct gene or transcript features with positive counts in that sample.
Annotation coverage
Detected transcript features matched to a structural classification record.
FSM / ISM
Reference-matching / incomplete reference-matching splice structures.
NIC / NNC
New combinations of known splice sites / models containing new splice sites.
Antisense / intergenic
Opposite-strand gene overlap / no reference-gene overlap.
Fusion / genic
Multi-gene-associated models / other gene-overlapping models.
Model length / exons
Length in bp and exon count per detected transcript feature. Model length is not read length.
IQR / range
25th–75th percentiles / minimum–maximum. Model features are equally weighted.
  • Cell-level metrics use the same filtered cells with valid double.cell records.
  • Per-cell values are sample medians unless a mean or total is explicitly stated.
  • Assessments are descriptive comparisons within this run; no universal pass/fail score is assigned.
  • Structural classes and aggregate correlations do not establish isoform accuracy.
